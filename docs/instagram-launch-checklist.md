## 現行オンボの正しい順序

1. Instagram内ブラウザでは「SafariやChromeで開く」案内が先に出る。
2. 1画面目で「スマホには、撮った写真。ねてるねこには、自分で選んだ写真。」と、自分の写真を残す価値を伝える。
3. 2画面目で初めて「ねこくじ」を示し、写真を1枚選ぶと4匹が登場することを伝える。
4. OSの写真選択だけでは保存せず、選んだ写真の確認画面で「保存して、ねこくじへ」を押したときに `うちのこ` へ保存する。
5. 4匹を一覧で見せ、気になる1匹をタップすると大きな写真と「この子を選びますか？」を表示する。4匹へ戻ることも、今回は選ばないこともできる。
6. 「この子を選ぶ」で確定したあとに初めて、選んだ1匹がその日の `ねこだより` になったと説明する。
7. 完了画面では保存した自分の写真を主役にし、`うちのこを見る` または `ねこだよりを見る` へ進める。猫の名前や2枚目の写真は求めない。

「即時便の封筒をひらく」「猫の名前を入れる」「最初の写真から次の20時便を予約すると先に説明する」は旧オンボの見せ方であり、現行オンボのユーザー向け案内には使わない。
一方、写真保存後の内部予約と運用監視は現行仕様として維持する。画面で事前に約束しないことと、内部で次のよる8時便を準備することを混同しない。

## Instagram内ブラウザ

- [ ] 初回表示に外部ブラウザ案内が出る。
- [ ] 「URLをコピーする」で `src=instagram_bio` を含むURLをコピーできる。
- [ ] 「このまま試す」でも2画面の導入、写真の保存前確認、4匹一覧、大写真確認、完了まで進める。
- [ ] 写真選択だけでは保存されず、「保存して、ねこくじへ」のあとに正式な `うちのこ` の1枚として残る。
- [ ] 1匹を選ぶまで `ねこだより` を機能名として説明せず、選択後にその日の `ねこだより` になったと示す。
- [ ] 対応するJPEG/PNG/HEICが一度目から読み込め、選択し直しもできる。
- [ ] 再訪時に、完了した状態を不必要に最初からやり直さない。
- [ ] GoogleログインをInstagram内ブラウザの主導線にしない。

## Android Chrome

- [ ] reset入口から匿名でオンボを完走できる。
- [ ] 写真の保存前確認後に4匹が表示され、1匹を大きく見て選べる。
- [ ] 自分の写真が `うちのこ` に残り、選んだ1匹が `ねこだより` から見られる。
- [ ] 猫の名前や追加の写真を求めず、`うちのこ` または `ねこだより` へ進める。
- [ ] `QuotaExceededError`や、成功表示後の保存失敗がない。
- [ ] 通常タブではAndroid向けの「アプリをインストール／ホーム画面に追加」案内が出る。
- [ ] PWAを起動し直して、保存した自分の写真と選んだ `ねこだより` が残る。

## iPhone Safari

- [ ] reset入口から匿名でオンボを完走できる。
- [ ] 4匹が2列で収まり、横にはみ出さず、それぞれを無理なくタップできる。
- [ ] 写真の保存前確認、4匹一覧、大写真確認、選択後の完了まで進める。
- [ ] 保存した自分の写真と選んだ `ねこだより` が再訪後も残る。
- [ ] Safari向けの共有ボタンと「ホーム画面に追加」の案内が出る。
- [ ] PWAを起動し直して、`うちのこ` または `ねこだより` を開ける。

## 本番に出してはいけないもの

- 候補なしを作るためのテスト操作や候補追加ボタン。
- 赤・青のプレースホルダー画像。
- anonymous ID、submission ID、Storage path、deployment URLなどのデバッグ情報。
- 初回写真を入れる前のPWA追加要求。
- 空の通知許可要求。
- 読込中に説明のない無言画面。
- 1匹を選ぶ前に、4匹やねこくじそのものを `ねこだより` と呼ぶ説明。

## 写真とプライバシー

- [ ] 写真はユーザーが選んだ共有範囲で保存される。
- [ ] 「自分だけ」の写真は配達候補にならない。
- [ ] ねこだよりに送り主の名前、場所、アカウント、SNS情報を出さない。
- [ ] `cat-photos`は非公開で、表示は権限確認済みのURLを使う。
- [ ] Instagramなど外部SNSへ自動共有しない。

## 当日の停止条件

次のいずれかがあれば投稿を順延する。

- はじめられない。
- 写真を確定しても4匹が表示されない、または1匹を選べない。
- 写真選択だけで保存・送信される、または確定後も自分の写真が `うちのこ` に残らない。
- 選んだ1匹が `ねこだより` に残らない、または選んでいない猫が残る。
- 写真の消失、誤表示、重複保存が起きる。
- 共有範囲や他人の写真について疑義がある。
- 操作不能から復帰できない。

軽い見た目のずれだけなら証跡を残し、次回告知までのP1として扱う。
